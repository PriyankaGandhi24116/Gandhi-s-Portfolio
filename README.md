# 🚀 Priyanka Gandhi — Interactive 3D Portfolio

A modern and interactive 3D personal portfolio website showcasing my skills, projects, achievements, education, internship experience, and technical journey in **Power BI, MERN Stack, AI/ML, Web Development, and Creative Design**.

The portfolio combines a professional UI with **Three.js 3D animations, glassmorphism, interactive project demonstrations, responsive design, dark/light mode, and smooth animations**.

🚀 Getting Started

1️⃣ Clone the Repository

git clone https://github.com/PriyankaGandhi24116/Gandhi-s-Portfolio.git

2️⃣ Navigate to the Project

cd Gandhi-s-Portfolio

3️⃣ Run the Portfolio

You can simply open index.html in your web browser.

The project includes a server.ps1 file for running the portfolio locally.

Run:
